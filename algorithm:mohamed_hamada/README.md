# feature-planning-algorithms

مشروع سيارة ذاتية القيادة تتعلم من أخطائها وتتجنب العوائق باستخدام:
- **Arduino Mega**: للتحكم بالمحركات وقراءة الحساسات (4 Ultrasonic + VL53L0X Lidar)
- **ESP32**: للتخطيط الذكي (D* Lite + TEB + Q-Learning) مع FreeRTOS

## المميزات
- 🔄 **تخطيط ديناميكي للمسار**: خوارزمية D* Lite لإعادة التخطيط عند ظهور عقبات جديدة
- 📈 **توليد مسار سلس**: TEB (Timed Elastic Band) لتحسين المسار وتجنب العوائق المحلية
- 🧠 **تعلم معزز**: Q-Learning لتحسين القرارات وتفادي الاصطدام بمرور الوقت
- ⚡ **اتصال عالي السرعة**: UART مع مقاطعات (ISR) بين المتحكمين
- 🧵 **مهام متعددة على ESP32**: FreeRTOS للمعالجة المتزامنة

## هيكلة المشروع
- `source/mega/` – كود Arduino Mega (مقسم إلى HAL و APP و COM)
- `source/esp32/` – كود ESP32 (مخطط المسار مع FreeRTOS)
- `simulation/` – مخطط التوصيل للمحاكاة

## الخوارزميات
### D* Lite
خوارزمية تخطيط متزايدة تعيد حساب أفضل طريق عند ظهور عوائق جديدة، دون الحاجة لإعادة التخطيط من الصفر.

### TEB (Timed Elastic Band)
يحسّن سلسلة من وضعيات الروبوت لتصبح سلسة وآمنة مع مراعاة ديناميكيات الحركة والابتعاد عن العوائق.

### Q-Learning
يتعلم الوكيل سياسة مثلى من خلال التجربة والخطأ، ويُستخدم هنا لضبط التحكم النهائي بناءً على حالة البيئة (مسافات العوائق واتجاه الهدف).
